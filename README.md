# ParentControl

Локальная система Admin + Client для Windows. Клиентская служба хранит банк времени, расписание, промокоды и журнал на своём ПК. Admin управляет несколькими клиентами по локальной сети и сохраняет команды в очереди, пока клиент недоступен. Во время работы подключения к облаку нет.

## Что готово

- Служба клиента с автоматическим стартом Windows, локальным таймером и сохранением данных в `%ProgramData%\ParentControl`.
- Банк времени: добавление и списание 1–1440 минут из Admin. При списании остаток не уходит ниже нуля, а команда хранится в очереди до доставки; для неё нужна обновлённая версия Client. Расход идёт только при открытом сеансе Windows и разрешённом доступе. При выключении ПК, в спящем режиме, при стандартной блокировке Windows, ручной блокировке или вне расписания банк стоит. Если минуты добавлены при нулевом остатке, Client сохраняет их на паузе и ждёт нажатия «Продолжить работу» на экране блокировки; промокод из нуля работает так же.
- Ручные режимы «Блокировать», «Разблокировать», «Автоматически». Admin может задать предупреждение за 1–1440 минут до конца банка (0 выключает). Клиент покажет небольшую карточку с остатком и кнопкой «Сохранить минуты» при достижении порога; событие также попадёт в журнал.
- Пользователь клиента может сам выбрать «Сохранить минуты и заблокировать» в трее или в окне настройки. Банк останавливается, а на экране появляется кнопка «Продолжить работу». Она снимает только добровольную паузу и не обходит блокировку Admin, расписание или нулевой остаток.
- Расписание по дням и часам, в часовом поясе клиента. Пустое расписание разрешает любое время при наличии минут в банке.
- Полноэкранный экран блокировки с закруглённой карточкой, случайным фоном из галереи JPEG/PNG и вводом промокода. Внизу есть кнопки «Перезагрузка», «Выключение» и «Сон» с подтверждением. Служба повторно запускает экран, если его закрыли.
- Во вкладке «Экран блокировки» Admin можно добавить до 8 фото (до 3 МБ каждое и до 16 МБ всего), увидеть миниатюры и удалить выбранные. Фото передаются при связи с Client и хранятся на нём. Один фон случайно выбирается при каждом новом появлении экрана блокировки, без слайдшоу.
- Во вкладке «Правила получения минут» Admin пишет текст с заголовками, списками и выделением в Markdown. Он доставляется через очередь, хранится локально на Client и открывается закладкой с бумажкой на экране блокировки; закладка с часами возвращает к минутам. Пользователь Client может читать текст, а изменения отправляет Admin. Одиночные переносы строк, включая Shift+Enter в Admin, сохраняются на Client; пустая строка отделяет абзацы. При новом тексте справа от закладки правил появляется мягкое «эхо»; открытие правил отмечает их прочитанными на клиенте.
- Круглая кнопка администратора открывает временный технический доступ на 30 минут без расхода банка. Если работа закончилась раньше, в трее клиента есть «Завершить техобслуживание сейчас» — сразу вернутся обычные правила доступа. Начальный пароль — 1234; после подключения смените его в Admin в разделе «Локальный вход администратора». Новый пароль хранится на клиенте как PBKDF2-хеш с солью и начинает работать после доставки команды. После перезапуска службы технический доступ заканчивается.
- Пакетное создание промокодов, копирование выбранного или всех кодов, список оставшихся применений в Admin. Выбранные коды можно удалить (Ctrl/Shift для нескольких) или удалить все коды без отмеченных вводов. Удаление ставится в очередь и отзывает код на клиенте после доставки; до этого код может работать. Код работает при выключенном Admin-ПК после доставки. Через 24 часа после последнего применения Client удаляет исчерпанный код; Admin полностью убирает запись из своего каталога и списка спустя 24 часа после исчерпания или команды удаления, даже если Client не в сети. Непереданная команда отзыва остаётся в очереди до доставки. Для удаления командой Admin на клиенте сохраняется запись отзыва, чтобы задержанная команда создания не восстановила код.
- Очередь команд на Admin-ПК. Команда уходит при следующем подключении клиента; повторная отправка с тем же ID не начисляет время повторно.
- Поиск клиента по сохранённому ключу в локальной сети. Admin проверяет введённый IP через подходящие сетевые адаптеры и отправляет широковещательный запрос отдельно через каждый из них. Найденный рабочий адаптер запоминается для последующих команд. Если прежний IP перестал отвечать, запущенный Admin повторяет поиск примерно каждые 30 секунд, обновляет адрес той же записи и доставляет очередь. При поиске проверяются ключ и обычное соединение с клиентом.
- Журнал на клиенте и копия на Admin-ПК после подключения. Если Admin запущен, он опрашивает клиентов каждые 5 секунд. При потере связи статус меняется на «Нет связи» в карточке компьютера без всплывающего окна.
- Шифрование обмена AES-GCM по общему ключу; файлы с ключом и состоянием защищены Windows DPAPI. Порты клиента `48731/TCP` для команд и `48732/UDP` для поиска, правила брандмауэра только для частной локальной сети.

## Установка из двух EXE

Готовые EXE доступны в [GitHub Releases](https://github.com/MantyZOR/ParentControl/releases/latest). Папка `dist/one-click` содержит **ровно два файла**: `ParentControl.Admin.exe` и `ParentControl.ClientApp.exe`. Каждый EXE включает .NET, поэтому отдельно устанавливать Runtime и запускать PowerShell не нужно. Microsoft официально поддерживает .NET 10 на Windows 11 и на отдельных выпусках Windows 10 Enterprise/LTSC; для Windows 10 Home/Pro после окончания поддержки ОС официальная совместимость не гарантирована: [таблица Microsoft](https://learn.microsoft.com/dotnet/core/install/windows).

1. На своём ПК откройте `ParentControl.Admin.exe` и подтвердите запрос UAC. Первый запуск установит Admin в `%LocalAppData%\Programs\ParentControlAdmin`, добавит ярлыки с иконкой в меню «Пуск» и на рабочий стол, а также запись в «Установленные приложения», затем откроет установленную копию. В дальнейшем открывайте Admin из меню «Пуск». При каждом открытии окна Admin Windows запрашивает права администратора. Автозапуск при входе в Windows включается отдельно в окне Admin.
2. На управляемый ПК скопируйте только `ParentControl.ClientApp.exe` и откройте его двойным щелчком. Подтвердите запрос Windows UAC.
3. При первом запуске EXE автоматически скопирует себя в `C:\Program Files\ParentControl`, создаст службу Windows, настроит брандмауэр, ярлыки с иконкой в меню «Пуск» и на общий рабочий стол Windows, а также запись в «Установленные приложения». Откроется установленная копия Client с IP и ключом. Служба запускается сразу для подключения, но защита и блокировка остаются выключены. Окно настройки Client при каждом открытии запрашивает права администратора; служба и экран блокировки запускаются без запроса UAC.
4. Скопируйте показанные IP-адрес и ключ в подписанные поля Admin. Если IP уже введён, нажмите «Подключить компьютер» без поиска; поиск нужен для адреса, который изменился. Назначьте время.
5. Вернитесь к окну клиента и нажмите «Включить защиту». При нулевом банке времени появится экран блокировки. Если служба была остановлена, сначала нажмите «Запустить службу».

После настройки окно Client можно закрыть: служба продолжит работу в фоне и автоматически запустится вместе с Windows. При работающей службе в пользовательском сеансе появляется значок в трее. Наведение показывает остаток минут; меню позволяет поставить банк на паузу, досрочно завершить техобслуживание, открыть настройки или выйти из клиента после ввода пароля техобслуживания. Вход техобслуживания на экране блокировки тоже содержит защищённую паролем кнопку полного выхода. Выход останавливает службу до ручного запуска или следующего запуска Windows.

Закрытие окна Admin сворачивает его в трей: опрос клиентов и доставка очереди продолжаются, пока Admin работает. В трее видны число доступных клиентов и команд в очереди; пункт «Выйти из Admin» закрывает программу. После выхода или выключения Admin-ПК команды остаются в защищённом файле `%LocalAppData%\ParentControl\admin.dat` и отправятся после следующего запуска Admin. Клиентский таймер и уже полученные правила продолжают работать автономно.

На обоих ПК нужен профиль сети «Частная». Поиск по ключу работает, когда служба клиента запущена и оба ПК находятся в одной широковещательной локальной сети. Некоторые гостевые Wi-Fi, VPN и изолированные подсети блокируют широковещательный поиск; тогда укажите IP клиента вручную. Даже одинаковые адреса вида `192.168.1.x` не гарантируют связь, если ПК подключены к разным роутерам или изолированным сетям. Ключ храните в надёжном месте. Для новых правил брандмауэра на уже установленном клиенте откройте новый EXE и нажмите «Обновить установку». После обновления обоих приложений задайте новый пароль технического доступа в Admin; до доставки изменения на клиенте действует начальный пароль 1234.

Чтобы обновить Admin, выберите «Выйти из Admin» в трее и откройте новый `ParentControl.Admin.exe`: установленная копия будет заменена. Для обновления Client откройте новый `ParentControl.ClientApp.exe` и нажмите «Обновить установку». Оба приложения удаляются через «Установленные приложения» Windows; данные банка, ключ, настройки и журнал при удалении сохраняются. После удаления может остаться временная копия EXE в `%TEMP%`, которую можно удалить позже. У окон нет стандартной рамки; маленькие кнопки свернуть, развернуть и закрыть появляются при наведении на верхнюю часть окна. Клиентский экран блокировки учитывает DPI каждого монитора и показывает по центру круглые кнопки перезагрузки, выключения, сна и технического входа.

Промокод можно передавать пользователю после того, как он отмечен как доставленный. Admin показывает остаток применений по последней синхронизации с Client. Если Admin выключен, Client всё равно удалит исчерпанный код через 24 часа; отметка «Удалён» появится в Admin при следующем подключении. Команды в очереди находятся **на Admin-ПК**; если он выключен, их доставка начнётся после его включения и запуска Admin. Журнал за время отсутствия Admin хранится на клиенте и синхронизируется при подключении.

## Ограничения безопасности

У пользователя управляемого ПК есть права администратора Windows. Такой пользователь всегда может остановить службу, удалить программу, изменить систему или получить доступ к ключу через машинную DPAPI. Шифрование защищает от обычного редактирования файлов и чтения команд в локальной сети, но **не делает клиент неуязвимым для локального администратора**. Admin показывает потерю связи; без облака или третьего доверенного устройства нельзя доказать, была ли причиной остановка службы, выключение ПК или сбой сети. Полноэкранный интерфейс не является защищённым рабочим столом Windows и также может быть обойдён локальным администратором.

Установка выполняется в `C:\Program Files\ParentControl`, состояние клиента находится в `%ProgramData%\ParentControl`, настройки Admin — в `%LocalAppData%\ParentControl`. Служба имеет имя `ParentControlClient`; правило брандмауэра — `ParentControl LAN`.

## Проверка

`dotnet build ParentControl.slnx -c Release` — сборка всех приложений. `./publish-oneclick.ps1` создаёт два автономных EXE для передачи на ПК; это команда для сборки из исходников, пользователю установленной системы она не нужна.

`dotnet run --project ParentControl.Smoke/ParentControl.Smoke.csproj -c Release` — проверка невидимого создания окон, размеров диалога выхода, пароля техобслуживания, AES-GCM, DPAPI, добровольной паузы, порога предупреждения и жизненного цикла промокодов. Переменная PARENTCONTROL_UI_PREVIEW задаёт папку для невидимого рендера интерфейсов в PNG.

Первое испытание на двух реальных ПК должно проверить запуск службы после перезагрузки, полноэкранный экран, остановку банка при блокировке Windows, доставку очереди после отключения сети и отображение статуса «Нет связи» в Admin.
